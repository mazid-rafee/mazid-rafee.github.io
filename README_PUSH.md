# Portfolio redesign

This folder contains the completed redesign for `mazid-rafee/mazid-rafee.github.io`.

The existing `headshot.jpg` in the repository is reused and is not included here.

## Files
- `index.html`
- `style.css`
- `script.js`
- `documents/academic-resume.pdf`
- `documents/industry-resume.pdf`
- `documents/research-statement.pdf`
- `documents/teaching-statement.pdf`
- `documents/cover-letter.pdf`

## Push manually
From a clone of the repository, copy these files into the repository root, then run:

```bash
git add index.html style.css script.js documents/
git commit -m "Redesign personal academic portfolio"
git push origin main
```
